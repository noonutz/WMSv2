+# WMSv2 Sandbox
 
+This repository hosts the Smart Factory WMS monorepo under `wms-monorepo/`.
+Refer to `wms-monorepo/README.md` for detailed documentation and packaging guidance.
+
+To publish the deliverable ZIP to GitHub Releases, push a tag that matches `v*`
+(for example `v1.0.0`). The automated workflow assembles the archive and attaches it
+to the release for download.
